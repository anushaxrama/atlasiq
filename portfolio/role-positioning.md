# Truthful role positioning

## Data Engineering

Built AtlasIQ as an independent monthly batch platform: official Parquet extraction, immutable checksummed landing, deterministic sampling, transaction-safe partition replacement, quarantined invalid records, run audit metadata, Airflow orchestration and explicit backfills. Verified replay, source/schema failures and partial-load recovery with a separate PostgreSQL test warehouse.

## Analytics Engineering

Modeled a PostgreSQL star schema and dbt staging/intermediate/marts layers with an incremental trip fact, role-playing zone dimension, date/hour/vendor/weather dimensions and reconciliation/relationship tests. Documented grains, UTC/local alignment, revisions, sampling, missing values and publication semantics rather than treating dashboard totals as self-explanatory.

## Data Analytics

Developed 12 reproducible SQL analyses using CTEs, ranking, percentiles, rolling windows, weekday comparisons and exploratory median/MAD flags. Generated findings and charts from actual query results. Distinguished accepted sampled taxi activity from city-wide mobility, weather associations from causal effects, and observed fares from company revenue/profit.

## Software Engineering

Implemented typed FastAPI endpoints, bounded/parameterized queries, publication readiness, structured failure responses and a strict TypeScript dashboard with seven real-data views. Added API, contracts, transactional recovery, database, Docker/Airflow and browser validation. This is independent project work, not a claim of professional engineering employment.
